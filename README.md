# LazoBoombox

Carry a Boombox, place it in the world, add a LazoDiscs music disc, and hear the music from the Boombox's location through Plasmo Voice.

## Features

- Carry or place a Boombox; insert, remove, or swap its music disc.
- Dye it in a crafting table using 1–8 dyes. Mix colors like leather armor and dye it again later.
- Color the casing, handle, and cassette panel together.
- Place it in 16 directions, in 22.5° steps.
- Keep the color and inserted disc when picking up or breaking it. Creative middle-click and Ctrl+middle-click copy the color too.
- Use Plasmo Voice positional audio for placed Boomboxes.
- Configure volume, playback radius, ownership protection, and the simultaneous audio-source limit. The playback progress HUD is optional.

## Installation

LazoBoombox requires LazoDiscs and Plasmo Voice. For multiplayer, install all three mods on the server and on every player's client. Fabric builds also require Fabric API. For singleplayer, install matching builds in the game instance.

## Supported versions

Release builds follow stable Plasmo Voice 2.1.17 support. The Minecraft versions with at least one build are:

`1.16.5`, `1.17.1`, `1.18.2`, `1.19`–`1.19.4`, `1.20`–`1.20.4`, `1.21`, `1.21.1`, `1.21.4`, `1.21.6`–`1.21.8`, `1.21.11`, and `26.1`–`26.3`.

Loader availability varies by exact Minecraft version. Choose the matching file from the [GitHub releases](https://github.com/EyeCrasher07/LazoBoombox/releases), [Modrinth](https://modrinth.com/mod/lazoboombox), or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/lazoboombox).

## По-русски

Бумбокс можно носить с собой или поставить в мире. Вставь пластинку LazoDiscs, чтобы слушать музыку из его положения через Plasmo Voice.

### Возможности

- Носи и ставь бумбокс, вставляй, вынимай и меняй пластинки.
- Крась его красителями в верстаке: используй от 1 до 8 красителей. Цвета смешиваются, как у кожаной брони; бумбокс можно перекрашивать.
- Вместе с корпусом красятся ручка и кассетная панель.
- Ставь бумбокс в 16 направлениях с шагом 22,5°.
- Цвет и пластинка сохраняются при поднятии и разрушении. В творческом режиме цвет также копируется колёсиком и Ctrl+колёсиком.
- Позиционный звук Plasmo Voice для бумбокса, установленного в мире.
- Настраиваемые громкость, радиус воспроизведения, защита владельца и ограничение числа одновременно играющих источников. HUD прогресса воспроизведения можно отключить.

### Установка

Для LazoBoombox нужны LazoDiscs и Plasmo Voice. В мультиплеере установи все три мода на сервер и клиент каждому игроку. Для Fabric также нужен Fabric API. В одиночной игре установи подходящие сборки в клиентский экземпляр Minecraft.

### Поддерживаемые версии

Релизные сборки соответствуют стабильной поддержке Plasmo Voice 2.1.17. Хотя бы одна сборка есть для версий Minecraft:

`1.16.5`, `1.17.1`, `1.18.2`, `1.19`–`1.19.4`, `1.20`–`1.20.4`, `1.21`, `1.21.1`, `1.21.4`, `1.21.6`–`1.21.8`, `1.21.11` и `26.1`–`26.3`.

Наличие сборки для конкретного загрузчика зависит от версии Minecraft. Выбирай подходящий файл на [GitHub](https://github.com/EyeCrasher07/LazoBoombox/releases), [Modrinth](https://modrinth.com/mod/lazoboombox) или [CurseForge](https://www.curseforge.com/minecraft/mc-mods/lazoboombox).
